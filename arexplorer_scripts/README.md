# Arma Reforger Explorer Scripts

Bu klasör, [Arma Reforger Explorer](https://arexplorer.zeroy.com/index.html) web sitesinden indirilen Arma Reforger v1.1.0.42 oyun script kaynak kodlarını içermektedir.

**Kaynak:** https://arexplorer.zeroy.com/index.html  
**Versiyon:** Arma Reforger v1.1.0.42  
**Oluşturan:** Zeroy - MisterOutofTime'a teşekkürler  

## İçerik

Toplam ~3800 EnfusionScript (.c) dosyası aşağıdaki kategorilerde:

- **AI** - Yapay zeka scriptleri
- **Building** - Bina sistemleri
- **Camera** - Kamera sistemleri
- **Campaign** - Kampanya scriptleri
- **Character** - Karakter scriptleri
- **Components** - Oyun bileşenleri
- **Editor** - Eden Editor scriptleri
- **Effects** - Efekt scriptleri
- **GameMode** - Oyun modu scriptleri
- **Map** - Harita ve minimap scriptleri
- **Mission** - Görev scriptleri
- **Network** - Ağ scriptleri
- **Player** - Oyuncu scriptleri
- **Respawn** - Yeniden doğma scriptleri
- **UI** - Kullanıcı arayüzü scriptleri
- **Vehicle** - Araç scriptleri
- **Weapon** - Silah scriptleri
- Ve daha fazlası...

Bu scriptler Minimaphud modu geliştirmek için referans olarak kullanılabilir.
